# SuperDummy 0.2.2 — release summary

Released **31 October 2026**. This release combines the painting/Mosaic work originally labelled 0.2.5 with the 0.2.2 camera, measurement and usability queue.

## Included

- [x] Six painting tools, Face/Block coverage where applicable and native game-paint storage.
- [x] Area shapes/connectivity, Fill, continuous Paint/Eraser, plane lock and stroke directions.
- [x] Live material previews and simplified region outlines.
- [x] Mosaic image loading, preview, colour/grayscale, fitting/detail/blending settings and one-step Apply.
- [x] Dialog mouse handover, safe Undo/Redo tool retention, Inspector/status-bar improvements and remembered V search.
- [x] Axis camera presets, perspective/ortho, depth correction and local camera-view sidecars.
- [x] Laser level, draggable ruler and construction-guide planes, with metre scales and shortcuts.
- [x] Beginner help and example screenshots.

## Validation scope

The author tried the reported workflows in the application and reported satisfactory results, including the last shape-search correction. This is a record of those trials, not an exhaustive test matrix. Release build, package contents, checksums and privacy checks are recorded during release preparation; the final asset hashes are attached to the release.

Not separately confirmed in this release: every camera-sidecar save/failure path, every paint/rotation/game combination, all large-prefab performance cases or a new in-game regression run. No GUI or automated tests are run as part of packaging.

## Still outside this release

Emergency autosave/recovery, water editing, mod-added block loading, custom game textures, whole-region moving/copying, and full gameplay-mechanism authoring. Moving a finished ruler's endpoints is an optional later enhancement.
